## Time-consuming manual configuration

Configuring complex networks is a very manual and slow process.

## Need for tool-specific knowledge

- Tools such as Open5GS and UERANSIM require mastery of their interfaces, parameters and configurations.
- Professionals need to keep up with changes and new versions of the different technologies.

## Difficulty adapting and reconfiguring

- Changes in network requirements force configurations to be reviewed and adjusted.
- Manual configuration makes it hard to adapt quickly to new scenarios.

## Softwarization and growing network complexity

- The shift to software-based networks makes them more adaptable, but increases the number of configurations and interactions to manage.
- Deploying and configuring several systems manually becomes difficult as the network grows.
