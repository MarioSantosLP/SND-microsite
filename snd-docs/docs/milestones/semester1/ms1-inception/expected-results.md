---
title: Expected Results
sidebar_position: 6
---

- **Working SND Agent prototype:** users describe a network and computing scenario in natural language, and the agent turns it into the required configurations and actions.
- **Documentation-based knowledge base:** a RAG system over manuals, API documentation, configuration templates and examples gives the agent the technical information it needs.
- **Planning and configuration generation:** each request becomes a deployment plan that accounts for parameters, dependencies, constraints and execution order.
- **Infrastructure deployment and reconfiguration:** configurations are generated and applied automatically to deploy or reconfigure a virtual 5G infrastructure.
- **Validation and error handling:** the system checks that components are running and that the final state matches the request, feeding any errors back to correct itself.
- **Interaction and monitoring interface:** users submit requests, revisit previous networks, and view the deployment plan, its status, results and errors.

Together, these results will deliver a system that removes most of the manual work from deploying a 5G core, grounded in real documentation rather than hand-written configurations, and able to check and correct its own output before a network is considered ready. Saved networks and configurations let deployers reuse previous work instead of starting over, making network setup faster, more reliable and easier to adapt to new scenarios.
